Iracyakora Ltd is a polished, modern business website for a hardware and architectural ironmongery supplier. The project showcases the company’s product focus, service areas, and direct contact channels through a responsive multi-page static site.

## ✨ Highlights

- Clean and professional landing experience for a hardware business
- Responsive design for desktop, tablet, and mobile
- Dedicated pages for products, about, projects, contact, and privacy
- SEO-friendly metadata, sitemap, and web manifest support
- Netlify-ready structure with a contact form success flow
- WhatsApp and phone contact actions for quick enquiries

## 🧱 Tech Stack

- HTML5 for page structure
- CSS3 for visual styling and responsive layout
- Vanilla JavaScript for small interactive enhancements
- Netlify for fast static hosting

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Parfai27/Iracyakora-Ltd.git
   cd Iracyakora-Ltd
   ```
2. Open the project in your browser, or serve it locally with a simple static server:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000/`.

## 🌐 Deployment

This site is prepared for deployment on Netlify.

Recommended steps:

1. Create a Netlify site from this repository
2. Set the publish directory to `.`
3. Deploy the project
4. Confirm pages such as `/`, `/products/`, `/about/`, `/projects/`, and `/contact/` load correctly
